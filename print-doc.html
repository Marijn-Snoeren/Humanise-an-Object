Humanize an Object — Friction Lab

An Empirical HCI Research Testbed on Intentional Interface Friction
Author: Marijn Snoeren • Academic Research • Next.js • TypeScript

1. Project Overview

Humanize an Object — Friction Lab is an experimental Human-Computer Interaction (HCI) research platform interrogating the dominant industry paradigm of fronless design. Modern digital interfaces prioritize frictionless immediacy, often reducing digital input to thoughtless, automated habits.

This project explores the reverse hypothesis: by giving a virtual cursor physical properties—such as viscosity, inertia, elasticity, surface resistance, and hesitation—the cursor transforms from a sterile pointer into an embodied object with tangible weight, vulnerability, and intentionality.

  • Tech Stack: Next.js (App Router), TypeScript, Tailwind CSS.
  • Design Language: Inspired by the Scandinavian editorial aesthetic of the Wise design system (Soft Salie #e8ebe6, Ink #0e0f0c, Vivid Lime #9fe870, and 24px pill radii).

3. Experimental Prototypes

Each trial implements a standardized pre-trial calibration gate ([ CLICK TO START EXPERIMENT ]) at the bottom baseline. This guarantees hardware and virtual cursor coordinates synchronize with zero spatial offset before telemetry recording initiates. Upon completing an experiment, all simulated friction deactivates immediately, returning to unconstrained 1:1 hardware control.

4. Telemetry Analytics Dashboard (/dashboard)

Quantitative evaluation is built directly into the client-side testing flow. All experimental trials log high-frequency interaction data to browser localStorage upon trigger confirmation.

  • Time-to-Target (ms): Elapsed duration from calibration release to target confirmation.
  • Path Distance (px): Cumulative trajectory length traveled by the cursor in screen pixels.
  • Movement Efficiency Ratio (MER): Straight-line distance divided by actual distance (1.0 = optimal linear vector).
  • Friction Events: Total instances of boundary breaches, snap detents, slip failures, or resistance triggers.
  • Export: One-click CSV export of the full raw dataset for statistical processing in R, SPSS, or Python.

5. Theoretical Framework & Academic Literature

  • Design Frictions for Mindful Interaction: Cox, A. L., Gould, S. J., Cecchinato, M. E., Iacovides, I., & Renfree, I. (2016). Demonstrates that strategically inserted cognitive and motoric resistance disrupts mindless automaticity and cultivates reflective decision-making.
  • Micro-Boundaries and Habit Interruption: Sarker, H., et al. (2014); Park, S. Y., & Kaye, J. (2019). Validates small interaction barriers prior to high-consequence interface triggers to eliminate accidental, absent-minded execution.
  • Where the Action Is: Foundations of Embodied Interaction: Dourish, P. (2001). MIT Press. Establishes the phenomenological basis for translating abstract software commands into physically intuitive constructs through simulated mass, resistance, and material constraints.
